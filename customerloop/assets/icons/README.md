# Map Marker Icons

This folder contains custom marker icons for Google Maps.

## Required Icons (64x64 PNG)

1. **user_location.png** - Blue pin for user's current location
2. **business_location.png** - Red pin for business locations
3. **customer_location.png** - Green pin for customer addresses
4. **destination.png** - Orange pin for destinations

## How to Add Icons

### Option 1: Use Free Icons (Recommended)

1. Visit [Flaticon.com](https://www.flaticon.com/)
2. Search for "map marker" or "location pin"
3. Download as PNG (64x64 or 128x128)
4. Rename and place in this folder

### Option 2: Create Your Own

Use any image editor:
- Size: 64x64 pixels
- Format: PNG with transparency
- Color: Match your app theme
- Simple design (looks good at small size)

### Option 3: Use Material Icons

The app will use Material Design icons as fallback if custom icons are not provided.
